A Browser History Simulator is a software application that mimics the working of a web browser's history feature. It allows users to navigate between previously visited web pages using operations such as Visit, Back, and Forward.

### Description

The Browser History Simulator demonstrates how a web browser maintains a record of visited websites and manages navigation. It uses data structures, particularly Stacks, to implement browser navigation efficiently.

### Main Features

1. Visit Page: Add a new webpage to the browsing history.
2. Back Navigation: Move to the previously visited webpage.
3. Forward Navigation: Return to the next webpage after going back.
4. History Display: View all previously visited webpages.
5. Clear History: Remove the browsing history.
6. Current Page: Display the webpage currently being viewed.

### Working Principle

The simulator uses two stacks:

- Back Stack: Stores previously visited pages.
- Forward Stack: Stores pages visited after navigating backward.

When a new page is visited, it becomes the current page and the forward history is cleared.

### Objective

The main objective of this project is to understand the practical implementation of Stack Data Structures (LIFO) and demonstrate how browser navigation works using basic data structure operations.

### Technologies Used

- Frontend: HTML, CSS, JavaScript
- Data Structure: Stack
- Platform: Web Browser

Expected Outcome: A simple interactive browser history simulator that demonstrates how users navigate backward and forward between webpages, similar to a real web browser.
